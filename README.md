# CAMPUS_EVENT

A web-based Campus Event Management System developed to manage and organize college events efficiently.

## 📌 Project Description

CAMPUS_EVENT is designed to help students and administrators manage campus events in a simple and effective way.

The system allows users to create, view, register, and manage events through an interactive web interface.

---

## 🚀 Features

- User Registration and Login
- Create and Manage Events
- Event Details Display
- Student Participation
- Database Connectivity
- Responsive User Interface
- Admin Management
